PVCA 1.0 — Personal Voice Call Assistant

I missed an important call. An hour later I still didn't know who called or why. PVCA 1.0 was built in response. When a call is missed, Twilio forwards it to a Dograh AI voice agent that collects the caller's name, reason, and urgency. The data hits a Flask webhook on Hugging Face Spaces, gets summarised by Groq, and lands in Telegram in under 15 seconds. The trickiest part: Twilio demands a response within 5 seconds — so the webhook returns 200 immediately and processes async in a background thread. Entire stack costs $0/month.

Problem No way to know who called, why, or how urgent — without calling back manually
Key Challenge Twilio's 5-second webhook timeout — solved with async fire-and-forget: return 200 instantly, summarise in background thread
Impact Caller info in Telegram in <15s · 24/7 autonomous receptionist · $0 infrastructure cost
Twilio Dograh AI Flask Hugging Face Spaces Groq Telegram API Async Webhooks

AI Newsletter Digest System

Staying current across AI and tech newsletters meant spending 30–45 minutes every morning scanning emails. 90% of that time was noise — preambles, ads, repeated announcements. This pipeline ingests 10+ newsletters via RSS and IMAP, strips boilerplate using a normalisation layer, extracts key insights with an LLM, and delivers a concise 5-minute morning briefing to Telegram. Runs every day at 7 AM via GitHub Actions, costs nothing to operate, and has not required manual intervention since deployment.

Problem 30–45 min wasted daily reading newsletters for ~5 min of genuinely useful information
Key Challenge Inconsistent HTML across newsletter sources — solved with a normalisation layer before LLM, rather than relying on the model to parse messy markup
Impact 10+ newsletters → 1 briefing · 30–45 min saved daily · Zero manual effort since launch
Python GitHub Actions LLM Summarisation IMAP / RSS Telegram API HTML Parsing
