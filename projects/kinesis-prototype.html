Overview

Kinesis is an AI-driven system that simulates and manages crowd behavior in large-scale stadium environments using real-time data, predictive modeling, and intelligent intervention.

Features

  • Real-time crowd simulation (agent-based)
  • AI risk detection (density + velocity + panic)
  • Biometric zone monitoring (heart rate simulation)
  • GenAI Command Interface (natural language control)
  • AI ON/OFF comparison (baseline vs optimized)
  • Live visualization (heatmap, flow, predictions)

Tech Stack

  • Python
  • Streamlit
  • NumPy
  • Matplotlib

How to Run

pip install -r requirements.txt
streamlit run main.py
